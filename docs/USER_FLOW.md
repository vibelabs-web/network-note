## 1. 사용자 여정 개요

### 1.1 핵심 사용자 스토리

```
사용자로서 나는...

1. 📝 빠르게 메모를 작성하고 싶다
2. 🔗 메모 간의 관계를 쉽게 만들고 싶다
3. 🤖 AI의 도움으로 숨겨진 연결을 발견하고 싶다
4. 🌐 내 지식 네트워크를 시각적으로 보고 싶다
5. 🔍 이전에 작성한 메모를 빠르게 찾고 싶다
```

│  └─────────────────────────────────────────────┘                   │

│  ┌─────────────────────────────────────────────┐                   │

│  │                              ↓               │                   │

## 부록

### A. 키보드 단축키 전체 목록

| 단축키 | 기능 | 컨텍스트 |
|-------|------|---------|
| `Cmd/Ctrl + N` | 새 메모 | 전역 |
| `Cmd/Ctrl + S` | 저장 | 에디터 |
| `Cmd/Ctrl + K` | 검색 | 전역 |
| `Cmd/Ctrl + G` | 그래프 뷰 | 전역 |
| `Cmd/Ctrl + ,` | 설정 | 전역 |
| `Escape` | 닫기/취소 | 모달, 드롭다운 |
| `↑ ↓` | 항목 이동 | 드롭다운, 목록 |
| `Enter` | 선택/확인 | 드롭다운, 버튼 |
| `?` | 단축키 도움말 | 전역 |

### B. 에러 상태 처리

| 상황 | 메시지 | 액션 |
|-----|--------|-----|
| 네트워크 에러 | "연결에 실패했습니다" | [재시도] 버튼 |
| 저장 실패 | "저장에 실패했습니다" | [재시도] 버튼, 로컬 캐시 |
| 메모 없음 (404) | "메모를 찾을 수 없습니다" | [목록으로] 링크 |
| 서버 에러 (500) | "문제가 발생했습니다" | [새로고침] 버튼 |
| LLM 타임아웃 | "AI 분석이 지연되고 있습니다" | [취소] 버튼 |

### C. 로딩 상태 표시

| 상황 | 표시 방법 | 위치 |
|-----|----------|-----|
| 페이지 로드 | 스켈레톤 UI | 메인 콘텐츠 |
| 메모 목록 로드 | 카드 스켈레톤 | 목록 영역 |
| 그래프 로드 | 중앙 스피너 | 그래프 캔버스 |
| AI 제안 로드 | "분석 중..." + 프로그레스 | 제안 섹션 |
| 저장 중 | "저장 중..." 텍스트 | 상단 바 |
| 검색 중 | 입력 필드 내 스피너 | 검색 바 |
